By the end of this guide you will have created an API key, exported your base URL and key, and made your first authenticated REST request.

There is no node to run, no indexer to sync, and no disk space to provision. Sign in, get a key, and query CKB data in three steps.

## Create an API key

Sign in to the [dashboard](https://cellora-nuxt.vercel.app) with GitHub, open **API Keys**, and click **Create key**.

<Warning>
The full key is shown exactly once at creation. Copy it immediately — only its prefix and an Argon2id hash of the secret are stored, so a lost key is unrecoverable and must be reissued.
</Warning>

## Export your base URL and key

Copy your base URL from the dashboard and export both values so the examples in these docs work as written.

```bash
export CELLORA_BASE="<base-url-from-dashboard>"
export CELLORA_KEY="cell_<prefix>_<secret>"
```

## Make your first query

Send your key as a Bearer token on every data endpoint. That is the only change to your HTTP client setup.

```bash
curl -s \
  -H "Authorization: Bearer $CELLORA_KEY" \
  $CELLORA_BASE/v1/blocks/latest | jq
```
