The full, authoritative GraphQL schema. Field names are camelCase; they map one-to-one onto the snake_case REST fields.

```graphql
type Query {
  blocksLatest: Block
  block(number: Int!): Block
  cells(input: CellsInput!): CellsConnection!
  stats: Stats!
}

input CellsInput {
  lockHash: String
  typeHash: String
  isLive: Boolean
  limit: Int
  cursor: String
  includeData: Boolean
}

type Block {
  number: Int!
  hash: String!
  parentHash: String!
  timestampMs: Int!
  epoch: Int!
  transactionsCount: Int!
  proposalsCount: Int!
  unclesCount: Int!
  nonce: String!
  dao: String!
  indexedAt: String!
}

type GraphCell {
  txHash: String!
  outputIndex: Int!
  blockNumber: Int!
  blockHash: String!
  capacityShannons: Int!
  lock: Script!
  lockHash: String!
  lockKind: String
  type: Script
  typeHash: String
  typeKind: String
  data: String
  isLive: Boolean!
  consumedBy: ConsumedBy
}

type Script {
  codeHash: String!
  hashType: String!
  args: String!
}

type ConsumedBy {
  txHash: String!
  inputIndex: Int!
  blockNumber: Int!
}

type CellsConnection {
  data: [GraphCell!]!
  nextCursor: String
  meta: Meta!
}

type Meta {
  indexerTip: Int
  nodeTip: Int
}

type Stats {
  indexerTip: Int
  nodeTip: Int
  lagBlocks: Int
  snapshotAgeSeconds: Int!
  isStale: Boolean!
}

type Subscription {
  blocksLatest: GraphBlockMinedEvent!
  cells(lockHash: String!): GraphCellCreatedEvent!
}

type GraphBlockMinedEvent {
  number: Int!
  hash: String!
  parentHash: String!
  timestamp: Int!
}

type GraphCellCreatedEvent {
  txHash: String!
  outputIndex: Int!
  blockNumber: Int!
  lockCodeHash: String!
  lockHashType: Int!
  lockArgs: String!
  lockHash: String!
  typeCodeHash: String
  typeHashType: Int
  typeArgs: String
  typeHash: String
  capacityShannons: Int!
}
```

## Notes

- **`cells` pagination** mirrors REST: `nextCursor` is opaque and `null` on the last page. Pass it back as `CellsInput.cursor`. See [Pagination](/pagination).
- **`data`** on `GraphCell` is populated only when `CellsInput.includeData` is `true`.
- **`lockKind` / `typeKind`** on `GraphCell` carry the canonical short label for a registered script, or `null` for custom / unknown scripts.
- **Subscriptions** stream over WebSocket. `blocksLatest` emits every newly indexed block; `cells(lockHash: ...)` emits newly created cells whose lock hash matches.
- **`Stats` and `Meta`** carry the same tip/lag signals as the REST responses. See [Tip lag and read freshness](/tip-lag-and-freshness).
