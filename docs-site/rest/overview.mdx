The REST surface lives under `/v1/*` and mirrors the [OpenAPI 3.1 specification](/rest/openapi). It is a read-only HTTP surface over indexed CKB data.

## Base URL

```bash
export CELLORA_BASE="<base-url-from-dashboard>"
```

Copy your base URL from the [dashboard](https://cellora-nuxt.vercel.app). Which network it points at is covered in [Networks](/networks).

## Conventions

- **JSON everywhere.** All responses are JSON.
- **Hex format.** Hashes are `0x`-prefixed lowercase hex.
- **Auth.** Every data endpoint requires `Authorization: Bearer <key>`. See [Authentication](/authentication). The only public paths are `/v1/health`, `/v1/health/ready`, and `/v1/openapi.json`.
- **Pagination.** List endpoints return `{ data, next_cursor, meta }` with opaque cursors. See [Pagination](/pagination).
- **Errors.** Non-2xx responses use a single envelope. See [Error handling](/errors).

## Common response headers

| Header | On | Meaning |
| --- | --- | --- |
| `x-request-id` | all | Unique request id, echoed from the client or generated server-side. |
| `x-indexer-tip` | 2xx | Tip block number observed at response time. |
| `x-indexer-tip-stale` | 2xx | `true` when the tip snapshot is older than the staleness threshold. |
| `X-RateLimit-Limit` / `X-RateLimit-Remaining` / `X-RateLimit-Reset` | 2xx | Token-bucket state. See [Rate limiting](/rate-limiting). |
