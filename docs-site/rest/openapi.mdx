---

The REST surface is described by an OpenAPI 3.1 specification. `GET /v1/openapi.json` serves it and is public — no API key required.

## Fetch the spec

```bash
curl -s $CELLORA_BASE/v1/openapi.json | jq '.paths | keys'
```

The document matches the `/v1/*` surface documented here and reports `openapi: "3.1.0"`, version `0.1.0`, and the `FSL-1.1-ALv2` license.
