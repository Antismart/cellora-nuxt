---
title: "GET /v1/cells"
description: "Paginated cell query by exactly one of lock_hash or type_hash, with is_live, limit, cursor, and include_data."
---

Paginated list of cells matching a lock or type script hash. Requires authentication.

Exactly one of `lock_hash` or `type_hash` must be supplied. Both must be `0x`-prefixed 32-byte hex (64 hex characters after the prefix).

## Query parameters

<ParamField query="lock_hash" type="string">
  `0x`-prefixed 32-byte hex. Required if `type_hash` is absent.
</ParamField>

<ParamField query="type_hash" type="string">
  `0x`-prefixed 32-byte hex. Required if `lock_hash` is absent.
</ParamField>

<ParamField query="is_live" type="boolean">
  `true` for unspent cells, `false` for consumed cells. Omit to return both.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Page size. Maximum `500`.
</ParamField>

<ParamField query="cursor" type="string">
  Opaque cursor. Pass the `next_cursor` from the previous response to fetch the next page. See [Pagination](/pagination).
</ParamField>

<ParamField query="include_data" type="boolean" default="false">
  Include the raw cell `data` blob on every cell. Off by default because cell data can be large.
</ParamField>

## Request

```bash
curl -s \
  -H "Authorization: Bearer $CELLORA_KEY" \
  "$CELLORA_BASE/v1/cells?lock_hash=0xabc...&is_live=true&limit=10" | jq
```

## Cell fields

| Field | Type | Notes |
| --- | --- | --- |
| `tx_hash` | string | Hash of the transaction that created the cell. |
| `output_index` | integer | Output index within that transaction. |
| `block_number` | integer | Block that created the cell. |
| `block_hash` | string | Hash of that block. |
| `capacity_shannons` | integer | Cell capacity in shannons. |
| `lock` | object | Lock script (`code_hash`, `hash_type`, `args`). |
| `lock_hash` | string | Hash of the lock script. |
| `type` | object \| null | Type script, or `null` if none. |
| `type_hash` | string \| null | Hash of the type script, or `null`. |
| `is_live` | boolean | Whether the cell is unspent. |
| `consumed_by` | object \| null | Where the cell was spent, if consumed. |
| `data` | string | Raw cell data — present only when `include_data=true`. |

Recognized lock and type scripts are tagged; see [Well-known script tagging](/script-tagging).

## Errors

| Status | Code | When |
| --- | --- | --- |
| 400 | `bad_request` | Both or neither of `lock_hash`/`type_hash`, invalid hex, wrong hash length, or `limit` of 0 or above the maximum (500). |
| 400 | `invalid_cursor` | Cursor is malformed, tampered, or references a tx hash of the wrong length. |

See [Error handling](/errors).
